# Bloom Business Suite

Build a web-based ERP system for a flower shop business. All data entry is manual — no third-party integrations, no payment gateways, no external APIs. Use a clean, professional dashboard layout with a left sidebar for navigation and a top bar showing the logged-in user and date. TECH & STRUCTURE - Use Supabase for the database and authentication (built into Lovable). - Role-based login: Owner (full access) and Staff (limited access — no financial reports, no settings). - Responsive layout, works on desktop and tablet. =========================================== 1. DASHBOARD (home page) =========================================== - Cards showing: Today's Sales, Today's Orders, Pending Deliveries, Low Stock Alerts, Total Customers, Outstanding Invoices (unpaid amount). - A simple bar chart: Sales for the last 7 days. - A simple pie chart: Top 5 selling flower/product types this month. - Recent Activity feed: last 10 orders/invoices created. =========================================== 2. DAILY SALES REPORT =========================================== - A page listing all sales transactions with columns: Date, Invoice #, Customer, Items, Quantity, Amount, Payment Status (Paid/Unpaid/Partial), Staff who recorded it. - Filter by date range, customer, and payment status. - Auto-calculated daily total, weekly total, monthly total at the top. - "Export" button to download the filtered report as PDF or CSV. - Ability to manually add a sales entry (in case it wasn't linked to an order). =========================================== 3. INVOICING =========================================== - Create Invoice form: select customer (or add new), select items from inventory (auto-fills price, editable), quantity, discount field, tax field (manual %), auto-calculated subtotal/tax/total. - Invoice status: Draft, Sent, Paid, Partially Paid, Overdue. - Manually mark invoice as paid and enter amount paid + payment method (Cash/Bank Transfer/Card/Other) and date. - Printable/downloadable invoice as PDF with business logo, address, and invoice number (auto-incrementing, editable format e.g. INV-2026-001). - Invoice list page with search/filter by customer, date, status. =========================================== 4. DELIVERY REPORT =========================================== - Delivery list linked to Orders: Order #, Customer, Delivery Address, Delivery Date, Assigned Rider/Staff, Status (Pending, Out for Delivery, Delivered, Failed). - Manual status update with timestamp and notes (e.g. "left at reception"). - Daily delivery report view: all deliveries scheduled for a chosen date, printable as a route sheet. - Option to attach a note/photo reference field (text only, no file upload needed unless you want it). =========================================== 5. CUSTOMER MANAGEMENT =========================================== - Customer list: Name, Phone, Email, Address, Customer Type (Retail/Corporate/Event), Notes. - Customer profile page showing: order history, total lifetime spend, outstanding balance, last order date. - Add/Edit/Delete customer manually. - Search and filter by name, phone, or type. =========================================== 6. ORDERS =========================================== - Create Order form: select customer, select flowers/products with quantity, delivery or pickup, requested date, special instructions (e.g. "no lilies", card message). - Order status flow: New → Confirmed → In Preparation → Ready → Delivered/Picked Up → Cancelled. - Order list with filters by status, date, customer. - Convert Order to Invoice with one click (pre-fills invoice from order data). =========================================== 7. INVENTORY =========================================== - Inventory list: Item Name, Category (Fresh Flowers, Foliage, Vases, Wrapping, Accessories, etc.), Unit (stems/bunches/pieces), Current Stock, Reorder Level, Cost Price, Selling Price, Supplier Name (text field, manual). - Manual stock adjustment form: Add Stock (with reason: New Purchase/Return) and Remove Stock (with reason: Sold/Wastage/Damaged/Expired). - Low stock alert badge when current stock falls below reorder level. - Stock movement history log per item (date, change, reason, staff who made the change). =========================================== 8. FLOWER MANAGEMENT =========================================== (This is inventory specifically for perishable flower stock, separate from general inventory since flowers need freshness tracking.) - Flower list: Flower Name, Variety/Color, Supplier, Date Received, Quantity Received, Cost per Unit, Expected Shelf Life (days), Current Stock, Status (Fresh/Aging/ Discard Soon/Discarded). - Auto-calculated "Days in Stock" based on Date Received (manual entry, no external API needed — just date math in-app). - Wastage log: record discarded flowers with quantity, reason, and date — feeds into a monthly wastage report. - Simple visual indicator (green/yellow/red) based on days in stock vs shelf life. =========================================== 9. OWNER MANUAL / HELP SECTION =========================================== - A static in-app page (accessible from sidebar, "Help / Manual") with collapsible sections explaining how to use each module: Dashboard, Sales, Invoicing, Delivery, Customers, Orders, Inventory, Flower Management. - Write this as simple step-by-step instructions with screenshots placeholders (I will add screenshots later) so any new staff member or the owner can reference it. - Include a short "Daily Checklist" section at the top: e.g. "1. Check low stock alerts, 2. Review today's deliveries, 3. Reconcile daily sales report, 4. Update flower freshness status." =========================================== 10. SETTINGS (Owner only) =========================================== - Business Profile: Name, Logo upload, Address, Phone, Invoice numbering format, Tax rate default. - User Management: Add/remove staff accounts, assign roles. - Category management for Inventory and Flower Management. =========================================== GENERAL REQUIREMENTS =========================================== - Every list page needs search, filter, and sort. - Every form needs validation (required fields, no negative numbers/quantities). - Currency format should be editable in Settings (default to my local currency). - All reports (Sales, Delivery, Wastage) should be downloadable as PDF or CSV. - Keep the UI simple and clean — this will be used daily by non-technical staff
